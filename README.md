🕉️ Telangana Temple Guide
A beautifully designed web application showcasing 8 famous temples in Telangana with details like location, significance, and visit information. Built using HTML, CSS, and JavaScript with a clean, responsive, and user-friendly interface.

🚀 Live Demo:
https://telangana-temple-guide.vercel.app/

📖 Overview
The Telangana Temple Guide is a static web application that provides an informative and visually appealing guide to 8 prominent temples across Telangana. The project highlights each temple’s unique spiritual significance, architectural beauty, and practical details for visitors. Built entirely with frontend technologies, it offers a smooth and responsive experience across devices.

✨ Features
Feature	Description
🏛️ 8 Famous Temples	Showcase of 8 well-known temples in Telangana
📍 Temple Details	Location, significance, and visiting information for each temple

🚀 Getting Started
Prerequisites
Ensure you have the following:

Any modern web browser

Node.js (optional, for local live server testing)

Installation
Clone the repository:


bash
git clone https://github.com/UradiSrilekha/telangana-temple-guide.git
cd telangana-temple-guide
Open the project in your browser:

Simply open index.html in any modern browser.

Or use a live server extension in VS Code for better preview.

Running the App Locally
Option 1: Direct Browser Opening
Navigate to the project folder and open index.html in your browser.

Option 2: Using Live Server (VS Code)
Install the Live Server extension in VS Code.

Open the project folder in VS Code.

Right-click on index.html and select “Open with Live Server”.

Your app will be accessible at http://localhost:5500.
